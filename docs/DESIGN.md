# 淡水小釣手：第一版實作說明

## 範圍

地區只限淡水，場域分類直接使用「漁人碼頭、油車口、公司田溪」，三者一次開放，不再細分防波堤、港內、外海等選單。公司田溪是整條溪流的遊戲化集合，包含溪流與感潮河段訪客，並不表示所有魚都在同一河段共棲。

裝備只提供路亞；UL／L／ML／M 是竿身強度等級。第一版所有裝備免費開放，不加入金幣、商店、活餌、粉餌或解鎖門檻。

## 技術

原生 Canvas 2D 繪製遊戲場景，HTML／CSS 製作選單、資訊條與原生 dialog；ES modules 分離資料、規則、控制器與呈現。沒有第三方執行期依賴，適合 GitHub Pages，所有素材本地產生，不需要 CDN。

未採原先提案的 Phaser，因第一版固定鏡頭、少量物件與簡單補間，用 Canvas 即可完成，並能完全省去依賴安裝。若日後增加角色行走、碰撞或大量精靈，可保留 `data.js` 與 `mechanics.js`，將 `scene.js` 換成 Phaser Scene。

`requestAnimationFrame` 驅動畫面；搏魚規則以 1/60 秒固定步長更新，畫面差異不改變模擬規則。單幀最大輸入 0.05 秒，失焦／背景分頁顯式暫停，不補算背景時間。裝備與場域只能在 setup 改動。

## 遊戲狀態

`setup → charging → casting → waiting → bite → fighting → landing → result → setup`。

咬鉤超時、斷線、鬆線或游離範圍進入 `escaped`，點擊重試回 setup。

狀態計時與轉移集中在 `main.js`，沒有散落的 `setTimeout` 動畫回呼。`scene.js` 讀取狀態繪製，不改動遊戲規則。存檔以回合 UUID 去重，魚獲只在起魚完成時結算。

## 操作數值

- 等待 4～9 秒；逗餌最多每 0.65 秒縮短 0.5 秒，至少保留 0.35 秒。
- 咬鉤反應窗 1.35 秒。
- 拉力綠色區間 25%～75%；過高或過低需持續一段時間才失敗。
- 魚衝刺前 0.45 秒提示；衝刺提高拉力與魚離岸距離。
- 竿強度影響收魚效率，操作值影響拉力升降速度。
- 擬餌的重量為此版本的釣組總重量；更換竿時自動修正不相容擬餌。
- 德州釣組對石斑魚的相對權重有 1.15 倍微調。

6. [油車口釣遊紀錄：達克貝利](https://www.tackleberry.com.tw/20211104-11/?lang=tw)：有根釣與花身等釣獲描述，作為候選魚池輔助資料。

魚池是根據環境、區域資料與釣遊紀錄製作的遊戲化配置，沒有宣稱完整碼頭現地調查。公司田溪的個別調查紀錄也不代表常見度。所有 encounter weight 與餌料倍率都是遊戲設計值。

第一版只收錄適合路亞玩法的候選魚，未把偏粉餌的烏魚、臭肚當作主要目標。沒有加入未定物種的「刺規」，也沒有將金目鱸設定成淡水常見魚。

## 尺寸與重量

魚獲卡片與圖鑑重量以台斤、兩顯示（1 台斤 = 600 公克 = 16 兩），精確至 0.1 兩，不足一台斤只顯示兩。內部計算與存檔仍使用公克，保留原有進度相容性。

`length = 截斷常態分布(mean, sd, min, max)`，單位 cm，遊戲統一視作全長。

`weightG = k × lengthCm³ / 100 × condition`；`condition` 是平均 1、標準差 0.05、範圍 0.9～1.1 的截斷常態。

所有分布與 k 是合理量級的初始遊戲參數，不是當地魚群統計或經文獻校準的長重關係。若改用論文係數，需同時標明 a、b、長度種類（TL／FL／SL）、單位、族群與來源，不能直接混用。

尺寸超界採拒絕抽樣；最多 128 次後回退至合法平均值，避免異常亂數來源無限迴圈。內部不四捨五入，顯示時才格式化。最佳尺寸與最重紀錄可來自不同尾魚。

## 儲存

LocalStorage 以單一版本化物件保存。匯入僅接受已知欄位、合法物種尺寸重量與有限數值，修正失效裝備；檔案大小上限 1 MiB。匯入失敗不覆蓋現有紀錄；儲存不可用仍可遊玩並匯出本次記憶體中的進度。

這是可信任朋友之間的本機遊戲，沒有伺服器驗證、跨裝置自動同步或防作弊排行榜。

## 驗證

`node --test` 驗證所有相容釣組有魚可抽、尺寸與重量上下界、固定種子分布、各魚種與釣竿能成功起魚、斷線／鬆線失敗、固定步長一致性、重複結算與存檔匯入。

瀏覽器已實測拋竿、揚竿、拉力控制與起魚，成功釣獲黑鯛 27.7 cm／380 g；重新載入後圖鑑仍顯示 1/8 與該次紀錄。已檢查 390×844 手機預覽、公司田溪切換、UL 搭配亮片時的不相容選項停用；未發現水平溢出或瀏覽器 error／warn。此手機驗證為桌面瀏覽器尺寸模擬，尚非實機觸控測試。
